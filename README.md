# Customer Churn Analysis

## About the Project

I worked on this project to understand why customers leave a business and to identify patterns that might be useful for improving customer retention.

I used Excel for the initial data cleaning, PostgreSQL for the analysis, and Power BI to build an interactive dashboard.

## Tools Used

- Excel
- PostgreSQL / SQL
- Power BI

## What I Did

- Cleaned and prepared the customer data in Excel.
- Checked the dataset for missing values and duplicates.
- Loaded the cleaned data into PostgreSQL.
- Used SQL to explore customer churn and customer behaviour.
- Compared customers who stayed with customers who left.
- Looked at factors such as tenure, monthly charges, contracts and services.
- Created a Power BI dashboard to present the main findings.

## SQL Analysis

Some of the questions I explored were:

- How many customers have churned?
- How many customers have stayed?
- What is the overall churn rate?
- Which customer groups have higher churn?
- How does customer tenure relate to churn?
- Are customers with higher monthly charges more likely to churn?
- Which services or contract types are associated with customer churn?

## Power BI Dashboard

I created an interactive dashboard to make the analysis easier to understand.

The dashboard allows the user to explore customer churn and compare different customer groups using charts and filters.

## Project Files

- `customer_churn_cleaned_DATA_FINAL.xlsx` – Cleaned dataset
- `customer_churn_analysis-PROJECT.sql` – SQL queries and analysis
